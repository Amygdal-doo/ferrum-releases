# Ferrum releases

Downloads for the Ferrum developer tools by AMYGDAL d.o.o. Sarajevo. This
repository holds release builds only; there is no source code here.

## Install

1. Download **Ferrum Toolbox** from the newest `toolbox-v…` release
   (`FerrumToolbox-<version>-aarch64.dmg` for Apple Silicon Macs).
2. Open the DMG and drag **Ferrum Toolbox** to **Applications**.
3. Open Ferrum Toolbox and install the apps you want from it:
   FerrumIDE, FerrumAPI, FerrumGIT, FerrumData and FerrumTerm.

The toolbox keeps every app up to date, including itself. No GitHub account
is needed.

## What's in a release

Releases are tagged `<app>-v<version>` (for example `data-v0.2.0`). Every
file has a matching `.sha256` checksum. `catalog.json` describes each app's
status and is read by the toolbox.
